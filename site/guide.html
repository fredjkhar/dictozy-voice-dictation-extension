Set up Dictozy
  1. Install from the Chrome Web Store and pin Dictozy in Chrome’s Extensions menu.
  2. Choose a supported field. Select its microphone or use your assigned shortcut; allow microphone access only when you intend to dictate.
  3. Open the popup for Try dictation and settings: a 10-second default (1–30 seconds), language formatting and per-site controls.

In the installed extension, explicitly recorded audio goes through Dictozy’s backend to xAI for transcription. This website demo sends nothing.
