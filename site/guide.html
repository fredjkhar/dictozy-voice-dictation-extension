Install and start

To dictate on a website, start with a field where you would normally type. To explore this guide, all you need is this page.

  1. Add Dictozy to Chrome

    Open the Chrome Web Store listing and select Add to Chrome. Pin Dictozy from Chrome’s Extensions menu to keep its settings within reach.

  2. Pick a place to practice

    Open the Dictozy popup and select Try dictation, or click a supported message field on an HTTPS page. Opening practice or focusing a field leaves the microphone off.

  3. Start when you’re ready

    Select the microphone beside the field or use your assigned shortcut. If Chrome asks for microphone access, allow it only when you intend to dictate.

In the extension Turning assistance off keeps your list locally. Hints don’t guarantee a spelling. The popup also offers per-site controls, language-formatting hints and your assigned shortcut. English is the default; Automatic leaves language selection to the provider.

Troubleshooting

Use the symptom you see to pick the next check. You can always return to the practice page from the extension popup.

  • Microphone blockedCheck Chrome’s microphone permission for the site.
  • No microphone beside a fieldCheck site preferences and try a supported text field. Password and payment fields are excluded.
  • Shortcut doesn’t respondOpen the shortcut control in the popup to check the assignment for conflicts.
  • Connection or transcription errorRead the error and confirm the connection before making a fresh recording.
